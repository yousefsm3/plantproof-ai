# Data

All data in this folder is **synthetic** and fictional.

- `scenarios/` - demo observations for two incident scenarios (generated by `python -m plantproof.data_gen`).
- `reference_answers.json` - Blind Test answers. Only `plantproof/blind_test.py` reads this file. Because this repository is public, anyone can read it: the separation demonstrates the method, it is not a secret.
